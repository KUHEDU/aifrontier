# AI프론티어 팀 활동·영수증

팀별 스터디·회의 기록과 활동지원비 영수증 제출을 휴대폰에서 하는 웹 화면입니다.

- 화면: `index.html` (이 저장소의 GitHub Pages 주소)
- 데이터: 교육팀 구글 시트에 붙인 `Code.gs`(Apps Script 웹 앱). 사진·영수증 파일은 교육팀 구글 드라이브에 저장됩니다.
- 이 저장소에는 참가자 이름, 시트 주소, 영수증이 들어 있지 않습니다. 팀 링크에 담긴 팀 코드가 맞아야만 서버가 데이터를 읽고 씁니다.

## 처음 설정

페이지를 열고 [처음 설정하기]의 4단계를 따라 하면 됩니다(구글 시트 만들기 → Apps Script에 `Code.gs` 붙여넣기 → 웹 앱 배포 → URL 붙여넣기).

## 고칠 때

- `Code.gs`를 고쳤다면 Apps Script에서 [배포 → 배포 관리 → 편집 → 새 버전]으로 다시 배포합니다. 주소는 그대로입니다.
- 시험: `node test/unit.js`(서버 규칙), `node test/e2e.js`(휴대폰 화면 전체 흐름, Chrome 필요). 시험 파일은 저장소에 올리지 않고 이 폴더에만 둡니다.
